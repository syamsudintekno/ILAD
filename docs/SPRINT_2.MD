# SPRINT_2.md — Data Processing Layer

**Status:** ⏳ Planned

---

# Sprint Goal

Implement the **Data Processing Layer** by creating modules responsible for loading, validating, and preparing the EDOM dataset before any analytics are performed.

This sprint establishes the foundation of the analytics pipeline.

No statistical analysis, performance scoring (RPI), ranking, or visualization is implemented in this sprint.

---

# Learning Objectives

After completing Sprint 2, the developer should understand:

- Layered Architecture
- Separation of Concerns (SoC)
- Single Responsibility Principle (SRP)
- Data Pipeline Design
- Interface between modules
- Error Handling
- Defensive Programming
- Writing unit-testable Python modules

---

# Coding Objectives

Implement the following modules:

```
core/
├── loader.py
├── validator.py
└── preprocessing.py
```

Each module must follow the responsibilities defined in `ARCHITECTURE.md`.

---

# Module Responsibilities

## 1. loader.py

Responsibilities

- Read CSV file
- Verify file existence
- Detect empty file
- Return `pandas.DataFrame`

Forbidden

- Validation
- Cleaning
- Statistics
- Streamlit code

---

## 2. validator.py

Responsibilities

Validate:

- required columns
- duplicated rows
- missing values
- invalid score range (1–5)

Forbidden

- Cleaning
- Aggregation
- Statistics
- Performance scoring

Validator reports problems only.

It does **not** modify data.

---

## 3. preprocessing.py

Responsibilities

- Standardize column names
- Map indicators (P1–P20) to competency dimensions
- Aggregate records at lecturer level
- Prepare clean dataset for analytics layer

Forbidden

- Statistics
- Ranking
- Quartile
- RPI

---

# Acceptance Criteria

## Loader

- Reads CSV successfully
- Returns DataFrame
- Raises meaningful exception if:
    - file not found
    - file empty

---

## Validator

Detects:

- missing columns
- duplicated rows
- missing values
- scores outside 1–5

Returns structured validation results.

Does not modify the dataset.

---

## Preprocessing

Produces:

- standardized columns
- mapped competency dimensions
- aggregated lecturer dataset

Returns clean DataFrame.
